# SolarSense methodology

## Research question
Can daily weather observations and seasonal information be used to estimate next-day daily solar radiation at a point near Ghotki, Pakistan?

## Data
The project requests daily observations from NASA POWER at latitude 28.0167 and longitude 69.3167:
- ALLSKY_SFC_SW_DWN: all-sky surface shortwave downward radiation (kWh/m²/day)
- T2M: 2 m air temperature (°C)
- RH2M: relative humidity at 2 m (%)
- CLOUD_AMT: cloud amount (community-specific units)

The data endpoint and parameter availability should be checked when running the project. NASA POWER may revise or extend its archive.

## Prediction design
For each date t, the model uses weather features available for date t to predict solar radiation on date t+1. Seasonal sine/cosine features are calculated for the target date. The persistence baseline predicts that date t+1 solar radiation will equal the observed solar radiation on date t.

## Evaluation
The supervised observations are sorted by date and split chronologically. The earliest 80% is used for fitting; the latest 20% is held out for evaluation. MAE, RMSE and R² are reported for the model. MAE is also reported for the persistence baseline.

## Limitations
This is a point-based educational prototype, not a validated operational forecasting service. It uses a limited feature set and a simple model. Weather variability, cloud dynamics, data quality and spatial representativeness can affect performance. Solar radiation is not equivalent to electrical energy generated by a particular photovoltaic system.
