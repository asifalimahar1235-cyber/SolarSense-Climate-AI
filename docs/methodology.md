# SolarSense methodology

## Research question
Can daily weather observations and seasonal information be used to estimate next-day daily solar radiation at a point near Ghotki, Pakistan?

## Data
The enhanced benchmark requests daily observations from NASA POWER at latitude 28.0167 and longitude 69.3167, from 2019-01-01 through 2025-12-31:
- ALLSKY_SFC_SW_DWN: all-sky surface shortwave downward radiation (kWh/m²/day)
- T2M: 2 m air temperature (°C)
- RH2M: relative humidity at 2 m (%)
- CLOUD_AMT: cloud amount (community-specific units)

The data endpoint and parameter availability should be checked when running the project. NASA POWER may revise or extend its archive.

## Prediction design
For each calendar date t, the enhanced benchmark uses information available on date t to estimate solar radiation on date t+1. It preserves missing calendar days before target shifting and does not interpolate missing observations across time. Features include solar-radiation lags, rolling means, same-day weather observations, selected weather changes, and target-day seasonal sine/cosine terms.

## Model selection and evaluation
The enhanced notebook creates 2,550 supervised observations from 2,557 calendar records: 2,040 training observations and 510 chronological held-out test observations. It compares Linear Regression, Random Forest, Extra Trees, and HistGradientBoosting. Four-fold TimeSeriesSplit cross-validation is performed only within the training period for model selection. The later 20% is held out for final evaluation and is not used to select the model.

Two baselines are evaluated on the same held-out target dates:
- Persistence: tomorrow's solar radiation is estimated as today's observed solar radiation.
- Seasonal climatology: the training-period mean target for the same day of year.

The primary reported metrics are MAE, RMSE, and R². The reported Extra Trees result is a historical, single-location benchmark, not evidence of operational forecast reliability.

## Dashboard distinction
The Streamlit dashboard presents the saved outputs from the enhanced Extra Trees benchmark: model comparison, persistence and seasonal baselines, held-out predictions, error distribution, largest-error cases, and a NASA POWER data explorer. A separate experimental estimate refits the benchmark's Extra Trees configuration on all currently available labelled observations and predicts the day after the latest usable input date. This is not the historical holdout evaluation and is not live forecast validation.

## Limitations
This is a point-based educational prototype, not a validated operational forecasting service. Weather variability, cloud dynamics, data quality, forecast-input quality, and spatial representativeness can affect performance. Solar radiation is not equivalent to electrical energy generated by a particular photovoltaic system.
